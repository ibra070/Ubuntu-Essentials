# 🐧 Ubuntu Essentials for Network Students

This is my personal cheat-sheet for **Ubuntu/Linux** commands that I use during my studies. 🚀

## 📂 1. File & Directory Management
| Command | Description |
| :--- | :--- |
| `pwd` | Show current directory path |
| `ls -la` | List all files (including hidden) |
| `cd ..` | Go back one directory |
| `mkdir MyProject` | Create a new folder |

## 🌐 2. Networking Commands (Crucial!)
| Command | Description |
| :--- | :--- |
| `ip a` | Show IP addresses and interfaces |
| `ping -c 4 google.com` | Check connectivity |
| `netstat -tunlp` | Show active ports and services |
| `ssh user@ip_address` | Remote access to a server or router |

## 🛠️ 3. Package Management (APT)
| Command | Description |
| :--- | :--- |
| `sudo apt update` | Update the package list |
| `sudo apt upgrade` | Upgrade all installed packages |
| `sudo apt install <name>` | Install a new tool (like python3 or vim) |

---
### 💡 Study Tips
- Use `man <command>` to read the manual for any command.
- Always use `sudo` with caution!
